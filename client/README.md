# 🏥 EdMed Connect

A modern Hospital Management Platform built using the MERN Stack.

## Features

- Hospital Discovery
- Hospital Details
- Patient Authentication
- Hospital Admin Dashboard
- Super Admin Dashboard
- Department Management
- Doctor Management
- Ward Management
- Room Management
- Bed Management
- Appointment Booking
- Consultation Requests
- Contact Form
- Analytics Dashboard
- JWT Authentication
- Role Based Access Control

---

## Tech Stack

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS
- TanStack Query
- Axios

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Nodemailer

---

## User Roles

### Super Admin

- Manage Hospitals
- Manage Hospital Admins
- Manage Departments
- Manage Doctors
- Manage Wards
- Manage Rooms
- Manage Beds
- View Analytics

### Hospital Admin

- Manage their Hospital
- Manage Departments
- Manage Doctors
- Manage Wards
- Manage Rooms
- Manage Beds
- View Dashboard Analytics

### Patient

- Register/Login
- Browse Hospitals
- Book Appointments
- Submit Consultation Requests
- Update Profile
